# 💻 Developer Portfolio — Md Jannatul Ferdhous Emon

A modern, **fully-dynamic personal portfolio** with a sleek *Dark Developer /
Neon* theme — designed and built end-to-end with the **MERN stack** and
**TypeScript**.

### 🔗 Live: **https://jfemon.vercel.app**

---

## Overview

A fast, responsive, content-driven portfolio that showcases projects,
experience, skills and writing. Every section is data-driven and managed
through a secure dashboard, so the site stays up to date without any code
changes.

## ✨ Features

- ⚡ Animated, terminal-style hero with a typewriter intro
- 🗂️ Projects gallery with filters and detailed case-study pages
- 📝 Blog with Markdown rendering, search and related posts
- 💼 Experience timeline, skills, education & credentials
- 📬 Working contact form with email notifications
- 🌗 Dark / light theme, SEO-optimized, fully responsive
- 🔐 Secure admin dashboard for fully dynamic content management
- 📊 Privacy-friendly, cookie-less visitor analytics

## 🧰 Tech Stack

**Frontend:** React · TypeScript · Vite · Tailwind CSS · React Router ·
TanStack Query · Framer Motion

**Backend:** Node.js · Express · MongoDB (Mongoose) · TypeScript · JWT

**Tooling & Cloud:** Cloudinary · Vercel · GitHub Actions

> Built with a strict, type-safe, component-driven architecture and a
> consistent design system across the entire codebase.
